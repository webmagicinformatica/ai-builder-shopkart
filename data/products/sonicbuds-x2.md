# SonicBuds X2 Wireless Earbuds

**Model:** SB-X2 · **Category:** Electronics (earbuds) · **Price:** ₹1,999 · **Warranty:** 1 year, brand service centre

Bluetooth 5.4, 30 hours with the case, IPX4. **Not the same as** SonicBuds X2 Pro (SB-X2P, ₹3,499, active noise cancelling).

**Returns:** 7 days from delivery if unopened. Opened earbuds can be returned only if faulty.

**Troubleshooting:** if one earbud has no sound, put both in the case, hold the case button for 10 seconds to reset, then pair again.
